# RecruitAI
RecruitAI – AI-Powered Recruitment and Interview Automation System

Features:
- Resume Screening
- Resume Scoring
- AI Interview Analysis
- Speech-to-Text using Faster Whisper
- Voice Verification using SpeechBrain
- Candidate Recommendation using Decision Tree ML
- PDF Report Generation

Tech Stack:
- React.js
- FastAPI
- MongoDB Atlas
- Faster Whisper
- SpeechBrain
- Scikit-Learn
- Joblib
